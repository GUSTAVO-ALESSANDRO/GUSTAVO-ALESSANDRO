Olá!👋 Sou o Gustavo Alessandro de Souza Sabino, tenho 21 anos e sou natural de Lavras, MG. Estudo Ciência da Computação na UFLA (5º de 8 períodos) e sou graduado em Análise e Desenvolvimento de Sistemas pelo UNILAVRAS, formação na qual conquistei o prêmio de **Mérito Acadêmico**. Iniciei ambas as graduações no primeiro semestre de 2024 após concluir o ensino médio no Colégio Nossa Senhora de Lourdes, onde conquistei bolsas para as duas formações.

Durante todo o ano de 2025, participei do projeto **VetDex** 🐾, voltado ao cadastro e visualização de doenças animais para a veterinária do UNILAVRAS, sob orientação do professor [João Paulo](https://www.linkedin.com/in/joaopaulofcc/). Atuei no desenvolvimento da primeira versão do sistema, trabalhando fortemente no ecossistema mobile com React Native, no back-end com Node.js e Fastify, além de prestar suporte no front-end web com React.

Tenho afinidade com tecnologias como React, React Native, Express, Fastify e Node.js, além de conhecimentos em bancos de dados MySQL e PostgreSQL, Java e Python. Também tenho bastante interesse pelas áreas de Inteligência Artificial e Ciência de Dados. Pretendo seguir carreira como desenvolvedor web ou mobile e me considero uma pessoa esforçada, dedicada, responsável e colaborativa. Fora da tecnologia, sou apaixonado por futebol, tanto como jogador quanto como torcedor.
